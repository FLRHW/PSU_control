# CSV profiles

Public waveform examples are in [examples/](examples/). Each file contains timestamped setpoints and output-enable columns only. The GUI supplies the PSU connection, interpolation mode, update/readback intervals and ramps. The runner's waveform-only default is to restore the channel's original programmed settings after a run.

Historical numbered files and intentionally invalid inputs used by automated tests have been moved to `tests/fixtures/`.
